# Agent instructions

- Read the research question and scope in `report/main.tex` before gathering or editing evidence.
- Register new evidence in `data/sources.csv`. Record a stable locator, the access date for online sources, and relevant coverage or limitations.
- Add cited sources to `report/sources.bib` with the same IDs as the source register. Use `\cite{source-id}` at the point of use and verify that the source supports the claim.
- Distinguish observations, inferences, and open questions. Record collection methods and unresolved gaps in `notes/`.
- Preserve raw material in an approved location. Keep credentials, personal data, and confidential material out of Git.
- Run the LaTeX build command in the README before finishing report edits. Review the compiled PDF for layout and citation issues. Keep generated build files out of Git.
